# Quiz App

A simple web-based quiz application built with HTML, CSS, and JavaScript. The app presents a series of multiple-choice questions, lets the user select an answer, and shows the final score at the end.

## Features

- Multiple-choice quiz questions
- Answer validation with correct/incorrect highlighting
- Score tracking
- Next-question flow
- Restart option after finishing the quiz
- Responsive styling for a clean interface

## Project Structure

- `index.html` – app structure and quiz layout
- `style.css` – styling and layout design
- `script.js` – quiz logic and question rendering

## How to Run

1. Open the project folder in your browser.
2. Double-click `index.html` or serve the folder with a local web server.
3. Start answering the questions and see your final score.

## Example

The quiz includes questions about history and literature, such as:

- Who burned Moscow?
- Which play contains the line “To be, or not to be”?
- Who was the first emperor of Rome?
